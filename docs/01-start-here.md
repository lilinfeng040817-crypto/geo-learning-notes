# 从哪开始学

## 先说清楚自己想解决什么

这里把 GEO 理解为：研究品牌或门店怎样在生成式回答与搜索中被准确地发现、介绍、引用和推荐，并据实验证变化。不同产品的工作方式和数据入口不同，不能把某个平台、某个行业的经验写成通用算法。

例如，顾客可能问“某商圈附近有哪些健身房值得推荐”，也可能问“附近哪里可以先买单次体验”。这些问题对应不同需求。研究应从顾客的处境和真实表达出发，不从店名或产品术语倒推一个容易命中的问题。

## 几件容易混在一起的事

| 现象 | 可以说明什么 | 还不能说明什么 |
| --- | --- | --- |
| 按店名能够查到 | 这次查询有返回相关信息 | 不含店名时会被推荐 |
| 正文提到品牌或门店 | 本次回答出现了它 | 是正向推荐、信息准确或稳定出现 |
| 回答附了某网页链接 | 能看到这个引用入口 | 所有内容只来自该页，或该页造成了推荐 |
| 出现门店或商品卡片 | 本次出现了这种展示 | 等同正文排名或成交 |
| 回答明确建议选择它 | 这次有正向推荐 | 以后每次都会出现 |
| 有点击、咨询或成交 | 某个业务环节发生了动作 | 全部由这次 GEO 工作带来 |

## 两条阅读路线

想给门店做第一次试验，先读执行流程、测量方法和记录表；需要理解案例时，再回到大会材料和平台文档。

想给企业搭长期知识体系，先明确业务和责任，再组织事实与来源、内容与入口、发布记录和测量。技术工具应服务这些任务，不用工具数量代替实际交付。

## 学资料时保留三种判断

一手文档能支持的规则，附对应链接和范围。讲者的经验与案例，保留行业、时间、样本和原口径。自己的推断和待测想法，写明还需要什么验证。三者有联系，也有不同的证据强度。

同一场演讲的课件、转写和转载，通常不是三个独立实验。目录中列出了论文，也不代表已读完这些论文。找到链接、取得文件、读过正文与验证效果分别记录。
